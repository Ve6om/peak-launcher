### New
- Crash helper: when the game crashes or a mod loader stops it, Peak explains what went wrong in plain words and offers a fix: install a missing mod, pick another version of a mod that doesn't match, give the game more memory, or use the right Java. It shows up while Fabric's "Incompatible mods found" window is still open, too.
- Undo last update: updating mods (or switching one to another version) keeps the old files, so the Content tab can put them back in one click. Modpacks can go back to the version they were on before an update.
- Mod info in the Content tab: mods that only belong on players' computers are marked "Client only", and mods missing something they need say what, with a click to install it or turn it back on.
- Join with a friend: an Invite button (next to Play while you're on a server, and in an instance's Servers tab) copies a link friends can open to join you. Peak installs the same modpack for them first. On servers from Peak's server list, your Discord status gets a "Join on Peak" button; for other servers you can turn it on in Settings > Integrations.

### Improved
- Dropdowns throughout Peak now match its look, show instance logos (or the mod loader's icon), and work with the keyboard.
