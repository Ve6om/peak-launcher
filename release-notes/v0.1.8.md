### New
- Change your skin right in Peak: upload a skin file, switch between classic and slim arms, pick one of your capes, or go back to the default skin. Everything previews on the 3D model before you apply it.
- Your recent skins: Peak keeps a copy of every skin you wear, so you can switch back to an old one in one click
- Player lookup on the Accounts page: search any username to see their skin and cape in 3D, their past names and past skins (from Crafty.gg), with a link to their NameMC page
- Your account's UUID is shown on the Accounts page, click it to copy
- Remove a mod, resource pack or shader straight from its page, not just reinstall it. For mods, Peak offers to remove the mods that depend on it too.
- A Browse button when picking Java, so you can point Peak at any Java install
- Linux AppImage: Peak offers to add itself to your applications menu, so you can open it like any other app. You can turn this off again in Settings.
- Every release now comes with a SHA256SUMS.txt file so you can check your download is genuine

### Fixed
- The "copy page link" option when signing in with a code gave a Microsoft error. It now copies the plain sign-in page, and you type the code there.
- After changing an instance from vanilla to Fabric (or any loader), the save bar stayed up until you switched tabs
- The update prompt in Peak showed "Bug fixes and improvements" instead of the actual changes
