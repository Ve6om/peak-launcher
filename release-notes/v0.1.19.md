### New
- Screenshots: a new page in the sidebar with every screenshot from every instance, grouped by when you played. Open one full size, copy the picture, save it somewhere, or move it to the bin. Add your own tags to find them later, or tick a few and save them as a zip.
- Optimize: a button next to Play (and in the right-click menu) that picks memory, Java flags and Java for an instance, based on how many mods it has and how much memory your computer has. It shows what's set now and ticks what's already right. The numbers are a good starting point, not exact.
- Pick your Java: Peak can now use Eclipse Temurin or GraalVM instead of Mojang's Java. GraalVM often runs Minecraft a little faster. Peak asks once, the first time you press Play, and you can change it any time in Settings > Java & memory or per instance. Only the Java version a game needs is downloaded.
- Java already on your computer (including IntelliJ's .jdks, Gradle, SDKMAN and Scoop) now shows in an instance's Java list.
- Settings > Java & memory lists every Java Peak has downloaded and how much space each takes, with a button to remove them.
- More accent colours, your own colour (pick it or type RGB / hex), and a Rainbow option that cycles through them all.

### Improved
- Peak should be much smoother on Linux. The background glow and frosted panels were being redrawn constantly, which made Peak laggy on some systems (especially with NVIDIA). It looks the same; the slow drift of the glow is off by default on Linux and can be turned back on in Settings > Appearance.
- The background glow stops moving while Peak isn't in front or is minimized, so it uses almost nothing while you play.
