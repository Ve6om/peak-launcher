### New
- Find the broken mod: when a modded instance crashes and the crash helper can't tell why, Peak can find the mod behind it. It turns off half the mods, you play, you say whether it still crashed, and it repeats until one mod is left, about 9 tests for a 150-mod pack. The first test runs with every mod off, to check a mod is to blame at all. Mods that others need are only turned off along with those mods, so a test never fails over a missing dependency. At the end, keep the broken mod off or put everything back; stopping at any point puts every mod back as it was. Start it from the crash window or Manage on the instance page.

### Fixed
- Mods installed from CurseForge now count as installed when browsing Modrinth, and the other way round, so they show as Installed instead of offering to install a second copy.
- Installing a mod no longer asks for a dependency the instance already has from the other site (like Fabric API from a CurseForge modpack).
- CurseForge mods whose authors don't allow launcher downloads now open the browser download window, which moves the file into place, instead of showing an error.
