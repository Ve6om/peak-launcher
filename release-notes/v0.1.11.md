### New
- Discover servers: a new tab on the Servers page with servers to play on. Search and filter by vanilla or modpack, server type, Minecraft version, or a specific modpack, and see who's online, the server's message and its banner.
- Modded servers join in one click: press Play and Peak installs the server's modpack (from Modrinth, CurseForge or Technic), then joins
- Vote for servers from their page on peaklauncher.com, and save any server to My servers
- "Play in Peak" buttons on the website's server list now open Peak on that server
- Run a server? List it at peaklauncher.com/dashboard
