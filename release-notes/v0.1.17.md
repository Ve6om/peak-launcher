### New
- Settings has proper tabs now: General, Appearance, Java & memory, Game, Commands, Network, Integrations and About. Each shows on its own, and Peak remembers the last one you opened.
- Start Peak when your computer starts: a switch in Settings > General, off unless you turn it on. Peak opens minimized so it's out of the way.
- A Rage button: when a modpack fails to launch or the game crashes, the error message has a button that shakes Peak's window for five seconds. It doesn't fix anything, but it helps.
