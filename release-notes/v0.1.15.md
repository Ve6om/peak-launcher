### Fixed
- Installing a pack you downloaded from CurseForge yourself (like COBBLEVERSE) could start the install over and over, filling the screen with "Installing…" and error messages and creating lots of copies of the pack. It now installs once.
- If the downloaded file can't be installed, the download window says so instead of quietly trying again
- Once a pack Peak found in your Downloads folder is installed, Peak deletes the zip so it doesn't pile up. Files you pick yourself are left alone.
