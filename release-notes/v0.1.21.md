### Improved
- Fewer manual downloads: when a CurseForge file can't be downloaded by launchers, Peak now gets the exact same file from Modrinth if it's there. For some packs, like CobbleVerse, that means no manual downloads at all. This works for modpack installs, updates, and adding single mods.
- The server list now recognises a modpack you installed from the other site when it's the same pack and version (for example Prominence II from Modrinth for a server that lists the CurseForge pack), so Play joins straight away instead of asking you to install it again. Versions marked for one site only, like CobbleVerse's "[CF]" builds, still ask you to install the right one.

### Fixed
- CurseForge data packs in a modpack had broken download links and went in the mods folder. They now link to the right page and go in a datapacks folder.
