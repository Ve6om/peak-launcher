### New
- Environment variables: set them for every game in Settings → Game, or for one instance in its settings (an instance's value wins when both set the same name).
- Linux: MangoHud's performance overlay and "Use the dedicated graphics card" sit next to GameMode in Settings, and each can be changed per instance. Peak now tells you when GameMode or MangoHud isn't installed instead of the game failing to start.
- Check my connection: Settings → Network can test whether Peak reaches Mojang, Microsoft sign-in, Modrinth, CurseForge, the mod loaders, Java downloads and GitHub, and suggests what may be blocking any that fail.
