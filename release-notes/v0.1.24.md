### New
- Reset keybinds: each instance's Default game settings section has a button that puts its keys back to Minecraft's own, mods' keys included. The old settings are kept beside it as options-before-key-reset.txt.
- Clear defaults is now there in an instance's settings too, not only in Settings.

### Fixed
- Default keybinds copied from a Minecraft 1.12 or older instance no longer unbind every key in newer instances. Those versions save keys as numbers that newer ones can't read, so their keybinds are now left out when copying (you'll be told), and defaults already saved like that are skipped.
