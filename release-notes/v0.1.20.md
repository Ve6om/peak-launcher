### New
- Default game settings: set your keybinds, video, sound and control settings once, in Peak or copied from an instance you've set up in-game. Each instance has its own switches to use them, and they go in every time it starts. Playing one instance never changes another. Find it in Settings > Defaults.
- Shared resource and shader packs: add a pack in one instance and it shows up in the others that share packs, without taking extra space.
- Change a mod's version: press the arrows next to any mod from Modrinth or CurseForge to pick another version, newer or older, made for that instance.
- Check for updates now lists each mod with an update, from its current version to the new one, with its own Update button and Update all.
- Optimize can add well-known performance mods (Sodium, Lithium, FerriteCore, ModernFix and more). It's optional, skips anything already in the pack or that clashes with it, and Undo takes them back out.
- Storage page in Settings: see what's using space and clear the safe parts, like finished modpack downloads, Minecraft versions no instance uses, and old logs and crash reports.
- Modpacks have an Update button next to Play when there's a new version, and a version button the rest of the time. Both are also in the right-click menu.

### Improved
- Updating or switching a CurseForge modpack to a version that can't be downloaded by launchers now opens the direct download screen, like a new install does, instead of showing an error.
- When a mod is updated, the old version is only removed once the new one has downloaded, and mods you turned off stay off.
- Long error messages wrap instead of running off the edge of the window.
- Dialogs opened from Settings now open in the middle of the window.
